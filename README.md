# Hospital Emergency Room Analysis Dashboard

## Overview
Analysis of 103,905 emergency room records to monitor patient flow and operational efficiency.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers

## KPIs
- Patient Volume
- Wait Time
- Admission Rate
- Satisfaction Score

## Insights
- Peak patient hours identified.
- Referral trends analyzed.
- Operational bottlenecks highlighted.
